# Documentación de la Arquitectura

Este repositorio contiene la estructura inicial del proyecto según los requisitos:

- **services/**: Microservicios de FastAPI con SQLAlchemy y PostgreSQL.
- **gateway/**: Punto de entrada con Jinja2 y CSS puro.
- **infra/**: Infraestructura Docker Compose y Nginx.
- **docs/**: Documentación y plantillas para tu memoria.
